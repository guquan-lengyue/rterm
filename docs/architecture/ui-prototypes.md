# UI 原型设计（ASCII 线框图）

> 每个 View 一个原型：尺寸标注 + 控件列表 + 交互说明 + 数据流。
> 给 AI 开发者看的「蓝图」——不是给设计师的视觉稿。

## 2. SessionTreeView（会话树）

**右键菜单**（gpui MenuItem，右键节点时弹出）：
```
┌───────────┐
│ 🆕 新建会话 │   ← 始终可用
│ 📥 导入... │   ← 始终可用
│ ───────── │
│ ✏️ 编辑   │   ← 仅选中会话节点
│ 📋 复制   │   ← 仅选中会话节点
│ 🗑️ 删除   │   ← 仅选中会话节点 + 二次确认
│ 📤 导出... │   ← 始终可用
│ ───────── │
│ ▶️ 打开终端│   ← 仅选中会话（S5 实现；S3 灰显 + TODO tooltip）
│ 📁 打开SFTP│   ← 仅选中会话（S7 实现；S3 灰显）
└───────────┘
```

**交互**：
- 单击 → 高亮选中
- 双击会话节点 → 发射 `SessionConnectRequested`（S3 先 log）
- Enter → 同双击
- Delete → 删除当前选中 + 二次确认对话框
- 拖拽 → 改 folder（S3 先不做，S10 补）
- 文件夹节点前 `▶` / `▼` 图标 → 展开折叠
- `Ctrl+F` → 树内过滤（输入框浮在顶部）

**数据驱动**：
```
SessionStore.list() → 建树（按 folder.split('/') 分组）
AppEvent::SessionCreated   → cx.notify() 重绘
AppEvent::SessionUpdated   → cx.notify() 重绘
AppEvent::SessionDeleted   → cx.notify() 重绘
```

│ └─────────────────────────────────────┘   │
│                                           │
│ 🌐 高级                                   │
│ ┌─────────────────────────────────────┐   │
│ │ KeepAlive  │ [30  ]秒 ☑            │   │
│ │ 超时       │ [10  ]秒               │   │
│ │ ☑ 压缩                              │   │
│ │ 主题覆盖   │ [默认跟随全局    ▾]    │   │

│                                           │

**数据流**：
```
on "保存":
  1. 读表单 → 构造 Session
  2. rterm_crypto::dpapi_encrypt(password_bytes) → EncryptedString { version: 1 }
  3. SessionStore.upsert(session)
  4. app.emit(&state.event_bus, SessionUpdated { session_id })
  5. Modal.close()
```

## 7. StatusBar（状态栏）

```
┌──────────────────────────────────────────────────────────────────┐
│ ● ready  │  📟 Sessions: 0  │  📁 Transfers: 0  │  Ctrl+P  命令面板   │
└──────────────────────────────────────────────────────────────────┘
```

**字段**（左→右）：
| 位置 | 内容 | 来源 |
|------|------|------|
| 左侧 | `● ready` 或 `● error` | AppState / 当前连接状态 |
| 中间左 | 会话数 `📟 N` | `SessionStore.count()` |
| 中间 | 传输队列数 `📁 N` | S7 接 FileTransferProgress |
| 右 1 | 当前活动主机 | S5 接 SessionConnected |
| 右 2 | 全局快捷键提示 | 静态 |

## 10. 存储路径

```
%APPDATA%\rterm\
├── sessions.json           ← SessionStore 持久化（DPAPI 密文）
├── settings.json           ← Settings 持久化
├── known_hosts.json        ← S10 做（替代 ~/.ssh/known_hosts）
├── backup\
│   └── sessions_2026-11-13.json  ← S10 自动备份
└── logs\
    └── rterm_2026-11-13.log

%LOCALAPPDATA%\rterm\
├── cache\
│   └── thumbnails\         ← 占位（SFTP 远程图预览，S7 做）
└── crates\                 ← cargo 自己的，不碰
```
