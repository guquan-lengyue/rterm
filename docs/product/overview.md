# rterm — 项目概述

> 一个用 Rust + gpui 构建的跨平台远程终端管理工具，定位 sshxterm / Xshell 的开源替代。

## 1. 项目定位

| 项 | 说明 |
|----|------|
| 产品形态 | 原生桌面 GUI（Windows + macOS + Linux） |
| 语言/UI | Rust + [bezel-gpui](https://crates.io/crates/bezel-gpui)（Zed 的 gpui 库的活跃 fork） |
| 对标产品 | sshxterm、Xshell、FinalShell、Termius |
| 核心差异 | 纯 Rust、GPU 加速、离线单文件、无遥测、支持 SFTP ↔ 终端路径双向同步 |

### 1.1 MVP 功能范围（v1.0）

- **SSH 会话管理**：分组、收藏、跳板机、密码/密钥认证、ssh-agent、连接测试
- **远程终端**：xterm-256color 仿真、多标签、字体主题、滚动缓冲、日志记录
- **SFTP 文件管理**：双栏浏览、拖拽上传下载、批量队列、chmod、文件搜索
- **远程设备性能监控**：CPU / 内存 / Swap / 磁盘 / 网络 / 系统负载实时折线图 + Top 进程
- **会话导入导出**：JSON 格式，密码加密，冲突策略，自动备份
- **SFTP ↔ 终端路径同步**：双向/单向可配，防止回环

### 1.2 明确不做（v1.0 砍掉的）

- X11 转发（Xshell 的核心功能，Windows 上依赖 VcXsrv，MVP 跳过）
- Telnet / Serial / RDP 等非 SSH 协议
- 多用户协同 / 云同步
- AI 代码助手（未来插件化考虑）
- 可移植性优先，macOS/Linux 验证可延后

## 2. 详细功能列表

### M1. SSH 会话管理（SessionManager）

| 编号 | 子功能 | 说明 |
|------|--------|------|
| M1.1 | 会话列表树形展示 | 文件夹分组（如「生产环境 / 数据库服务器」），拖拽排序；右键菜单：编辑 / 复制 / 删除 / 重命名 / 导出 / 打开终端 / 打开 SFTP |
| M1.2 | 新建 / 编辑会话 | 基础：名称、主机地址、端口（默认 22）、用户名；高级：认证方式、超时秒数、KeepAlive、压缩开关、跳板机、终端主题覆盖 |
| M1.3 | 认证方式 | ① 密码（DPAPI 加密存储）② 私钥文件 `.pem` / `.ppk`（口令可选）③ ssh-agent 枚举选择 |
| M1.4 | 跳板机 ProxyJump | 可选配置，支持多级嵌套；连接时自动链式建通道 |
| M1.5 | 会话状态指示 | 树形图标：在线 / 离线 / 连接中；底部状态栏显示当前主机 + 延迟（ping）+ 重连次数 |
| M1.6 | 收藏 / 命令面板 | 侧边栏顶部收藏夹；`Ctrl+P` 命令面板模糊搜索会话快速打开 |
| M1.7 | 全局默认配置 | 会话未配置字段的回退默认值（默认端口 / 默认用户名 / 默认认证方式 / 默认主题 / 终端字体 / 终端尺寸） |
| M1.8 | 连接测试 | 点击「测试连接」按钮，异步尝试 TCP 握手 + SSH 握手 + 认证握手，弹出成功 / 失败（含错误码和建议） |

### M2. 远程终端（Terminal）

| 编号 | 子功能 | 说明 |
|------|--------|------|
| M2.1 | 标签页多开 | 每个会话一个或多个标签；支持同会话多标签（独立 PTY）；标签可关闭 / 重开 / 左右分屏（可选） |
| M2.2 | PTY 创建与销毁 | SSH 通道上分配 PTY；窗口 resize 同步 `resize_pty`；关闭标签自动释放；断线时自动重连（指数退避） |
| M2.3 | 终端仿真 | xterm-256color 兼容；256 色 + 真彩色；交替缓冲区（vim / nano / less / tmux 正常）；光标形状切换（方块 / 下划线 / 竖线） |
| M2.4 | 文本复制粘贴 | 鼠标左键选择自动复制；右键粘贴；`Ctrl+Shift+C` / `Ctrl+Shift+V`；三键复制模式可选（终端常见习惯）；OSC 52 远程剪贴板 |
| M2.5 | 字体渲染 | 等宽字体；支持 Powerline / Nerd Font 字形；字号缩放 `Ctrl+/Ctrl-/Ctrl+0` |
| M2.6 | 主题 | 内置 4 套：Solarized Dark / Light、Dracula、One Dark；允许前景 / 背景 / ANSI 16 色自定义；主题可 per-session 覆盖 |
| M2.7 | 滚动缓冲 | 可配置行数（默认 10000）；`Shift+PageUp/PageDown` 翻页；鼠标滚轮；回滚查找 `Ctrl+F`（MVP 简化版可用 page-through） |
| M2.8 | TUI 兼容验证 | vim / nano / htop / tmux / less / top 实测；`TERM=xterm-256color` 正确传递 |
| M2.9 | 会话日志 | 每标签可开关；输出保存为 `.log`；默认路径可配置；可选时间戳前缀 |

### M3. SFTP 文件管理（与终端联动）

| 编号 | 子功能 | 说明 |
|------|--------|------|
| M3.1 | 标签页打开 SFTP | 与终端标签平级，同会话可同时开终端 + SFTP |
| M3.2 | 双栏文件浏览 | 左：本地文件树 / 列表；右：远程文件树 / 列表；各有地址栏、面包屑、刷新、前进 / 后退 |
| M3.3 | 文件传输 | 拖拽上传 / 下载；右键上传 / 下载；批量队列；每个任务独立进度条 + 速度显示；完成通知；失败重试 |
| M3.4 | 远程文件操作 | 创建目录、重命名、删除（递归删除目录前二次确认）、chmod（可按权限位勾选）、查看属性（ls -l 解析） |
| M3.5 | 本地文件操作 | 与系统文件管理器联动（调用 shell），避免重造轮子 |
| M3.6 | 文件过滤与搜索 | 扩展名过滤；文件名模糊搜索；隐藏文件 / 系统文件开关 |
| **M3.7** | **SFTP ↔ 终端路径同步（核心）** | 见下文 M3.7 |
| M3.8 | 路径同步实现细节 | 终端侧：PS1 正则提取（主方案）+ 后台周期性 `pwd`（兜底，可配置）；SFTP → 终端侧：向 PTY 注入 `cd <path> && pwd` 并抑制回显；双向时 SyncBridge 维护 ignore 列表防回环 |

**M3.7 同步方向开关**（per-session 配置）：
- `Terminal → SFTP only`（默认）：用户在终端 cd 时 SFTP 跟随
- `SFTP → Terminal only`：用户在 SFTP 导航时终端执行 cd
- `Bidirectional`：双向联动（默认推荐）
- `Off`：完全关闭

### M4. 远程设备性能监控（ResourceMonitor）

| 编号 | 子功能 | 说明 |
|------|--------|------|
| M4.1 | 监控面板 | 独立标签，同一会话；顶部 6 个实时卡片：CPU、内存、Swap、磁盘总览、网络流量、系统负载 |
| M4.2 | 数据采集 | SSH 通道周期性（默认 2s）执行轻量脚本：Linux 读 `/proc/*`；macOS 兼容 `sysctl` / `vm_stat` |
| M4.3 | 时序折线图 | 每指标保留最近 60 个采样点（~2 分钟）；gpui Canvas 绘制；可暂停 / 恢复；可导出 CSV |
| M4.4 | Top 进程列表 | 实时刷新 Top 进程表：PID / 用户名 / CPU% / 内存% / 命令；列可排序 |
| M4.5 | 告警阈值 | 可设置 CPU > 90% 持续 10s 等阈值；触发时标签标题红色闪烁 + 系统通知 |
| M4.6 | 进程操作 | 右键进程：Kill（SIGTERM）/ Force Kill（SIGKILL）/ 友好提示（高风险操作，二次确认） |

### M5. 会话导入导出

| 编号 | 子功能 | 说明 |
|------|--------|------|
| M5.1 | 导出格式 | JSON（自描述），敏感字段（密码、私钥口令）用 AES-256-GCM 加密，密钥来自导出时用户输入口令 |
| M5.2 | 导出范围 | ① 全部会话 ② 指定文件夹 ③ 勾选若干会话 |
| M5.3 | 导入 | 读 JSON；冲突策略：覆盖 / 跳过 / 重命名；导入前预览 diff |
| M5.4 | 格式兼容（MVP 简化） | 仅支持 OpenSSH `~/.ssh/config` 导入；PuTTY `.ppk` 导入 / FinalShell 导入作为后续版本考虑 |
| M5.5 | 自动备份 | 每 24h 自动备份到 `%APPDATA%\rterm\backup\`，保留最近 7 份；可手动触发 |

### M6. 应用框架与公共组件

| 编号 | 子功能 | 说明 |
|------|--------|------|
| M6.1 | 主窗口布局 | 左侧会话树（可折叠、宽度可调）+ 右侧标签页区 + 底部状态栏；支持全屏标签模式（隐藏侧边栏 `F11`） |
| M6.2 | 全局快捷键 | `Ctrl+P` 命令面板；`Ctrl+Shift+N` 新建会话；`Ctrl+Tab` 切换标签；`Ctrl+,` 设置；`F11` 全屏；`Ctrl+T` 新标签；`Ctrl+W` 关闭标签 |
| M6.3 | 设置界面 | 分组：常规 / SSH 默认值 / 终端外观 / SFTP / 监控 / 高级；右侧即时预览（主题变更立即生效） |
| M6.4 | 日志与诊断 | 应用运行日志（`RUST_LOG` 可配）；帮助 → 导出诊断包（打包日志 + 版本信息 + 会话统计） |
| M6.5 | 持久化存储 | `%APPDATA%\rterm\sessions.json`（敏感字段 DPAPI 加密）；`%APPDATA%\rterm\settings.json`；`%LOCALAPPDATA%\rterm\cache\` |
| M6.6 | 错误处理 | SSH 断开自动重连（指数退避，最多 5 次）；认证失败 / 超时 / 主机密钥变更 / 网络错误 分别弹窗；主机密钥变更时三选一（接受 / 拒绝 / 永久接受并写入 known_hosts） |

## 4. 术语与缩写

| 缩写 | 全称 | 说明 |
|------|------|------|
| PTY | Pseudoterminal | SSH 通道上分配的伪终端 |
| SFTP | SSH File Transfer Protocol | ssh2 子系统 |
| OSC | Operating System Command | ANSI 转义序列类型，例 OSC 52 剪贴板 |
| CSI | Control Sequence Introducer | ANSI 转义序列类型 |
| DPAPI | Data Protection API | Windows 绑定当前用户的加密 API |
| AEC | Automatic Environment Control | 我们 SyncBridge 对路径同步的内部缩写 |
